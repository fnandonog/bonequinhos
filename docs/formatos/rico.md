# Formato "Como Ficou Rico" (perfil @comoficourico.oficial) — piloto a aprovar
- A história de como uma pessoa ou empresa ficou rica, contada como uma obra: cada etapa "constrói" a fortuna (contador de patrimônio no topo, igual ao gasto acumulado do "Você Construiu").
- Números com fonte (Forbes, balanços, entrevistas). Gancho: o começo humilde + o número final.
- Fecha com "a lição" em uma frase e pergunta para comentário. Nada de promessa de enriquecimento.
- Voz: a do Fernando no ElevenLabs (`5Ny27k6jpd2wJTdmbFsb`), aplicada pela plataforma (Configurações → Voz).
